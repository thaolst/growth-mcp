# Examples / Vi du

Try every layer of growth-mcp in 5 minutes with the synthetic datasets in this folder. All data is generated by `generate_data.py` with a fixed seed: realistic shape, no real product behind it.

Thu moi layer cua growth-mcp trong 5 phut voi data tong hop trong folder nay. Toan bo data sinh tu `generate_data.py` voi seed co dinh: hinh dang giong that, khong co san pham that nao dang sau.

## 2. Retention cohort from weekly counts

File: `retention_weekly.csv` (9 weeks of active user counts)

Ask Claude: "Run retention analysis on examples/retention_weekly.csv"

The tool auto-normalizes counts to rates. Actual output highlights:

```json
{
  "latest_retention_pct": 27.3,
  "biggest_drop": {"period": "week_0->week_1", "drop_pct": 42.0}
}
```

The curve flattens after week 6: the plateau sits near 27%, which the
`growth://frameworks` resource classifies as a strong week-8 band.

## 3. Segment balance stats

File: `segment_balances.csv` (3,000 users across 4 segments)

Ask Claude: "Summarize points_balance by segment in examples/segment_balances.csv"

Actual output highlights: the `power` segment is 10% of users but holds 43% of all points; the `new` segment averages only 82 points.

## 4. Redemption price elasticity per segment

File: `redemption_price_periods.csv` (4 price periods x 3 segments)

Ask Claude: "Analyze redemption elasticity per segment in examples/redemption_price_periods.csv"

Actual output:

```json
{
  "most_price_sensitive": "new",
  "least_price_sensitive": "power",
  "segments": {
    "new":    {"average_arc_elasticity": -1.949, "classification": "HIGHLY_ELASTIC"},
    "active": {"average_arc_elasticity": -0.91,  "classification": "MODERATELY_INELASTIC"},
    "power":  {"average_arc_elasticity": -0.296, "classification": "INELASTIC"}
  }
}
```

Reading: price promotions move the `new` segment strongly; for `power` users a price cut mostly gives margin away. This is the exact analysis behind deciding which segment gets the discounted redemption window.
